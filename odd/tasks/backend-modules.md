# Feature: backend-modules

Objective: make each vendor (Antigravity/Gemini today; Claude, GPT later) a self-contained backend module behind one contract, so the HTTP gateway stays vendor-neutral. Then resume Ticket 02 on top of it.
Branch: `feat/backend-modules` (base `34768b7`). Delivery: ask-on-risk. Test runner: `go test ./...`.

## Specs

- **S1** — User request (verbatim): "algo importante que quiero que trabajemos también, además de esto, es el hecho de que el apartado de antigravity/gemini sea un módulo, ya que he estado pensando que si esto sucede con este, también sucederá caso similar con claude, gpt, etc."
- **S2** — Scope decision (user answer): "Clientes oficiales propios" — each vendor is a backend that drives its own official local client (Antigravity `agy acp` since S7; Claude Code CLI, Codex CLI later); network egress is always done by the official binary. The contract must tolerate different protocols and lifecycles.
- **S3** — "si es necesario regresar a modificar cosas que ya habíamos hecho. Pues lo haremos": fix already-written artifacts that contradict reality. Since S7 the Antigravity transport is `agy acp` (ACP v1, JSON-RPC over stdio); GLOSSARY, ADR 0001, ADR 0002, README, spec and tickets 01–04 must describe that, and the ConnectRPC/`language_server.exe` description becomes history.
- **S4** — Antigravity-specific code (process spawn, ACP client, model selection) lives only under `internal/backend/antigravity`. Vendor-neutral code (contract, routing, HTTP ingress, OpenAI wire format, SSE) never imports a vendor package except at wiring time.
- **S5** — Confirmed by the user (L9): model ids are always prefixed, `<backend>/<model>` (e.g. `antigravity/gemini-3.8-pro`); `/v1/models` lists prefixed ids. Only the Antigravity backend is built now (no Claude/GPT stubs).
- **S6** — Ticket 02 (`.scratch/subpipe/issues/02-tracer-bullet-completion.md`) is built on the backend contract over `agy acp`, tested against a fake ACP agent (mock); no live probe with the user's account. Tickets 02–04 are re-scoped for ACP.
- **S7** — Direction decision (user answer, L10): "1" — accept the consumer-plan ToS risk the way the pi bridges do: use the subscription through the official client and build Ticket 02 on `agy acp` instead of `language_server.exe`.
